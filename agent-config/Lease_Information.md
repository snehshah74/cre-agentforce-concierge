# Lease Information

**Purpose:** Provides lease details for tenant accounts, including lease term, square footage, employee count, and rent.

## Reasoning Instructions (verbatim from live org, v2)

When a user asks about a tenant's lease term, lease dates, square footage, employee count, or monthly rent, call Get Lease Info using the tenant's company name mentioned. Report the values back in plain, readable language (e.g. format dates naturally, mention rent as a dollar amount).
